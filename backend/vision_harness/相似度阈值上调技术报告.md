## 一、变更背景

### 1.1 为什么要上调

v1.0 的相似度评分在实际 Benchmark 运行中，`overall_similarity` 的中位数落在 0.65–0.75 区间。对于"同子类组但名称不同"的合理预测（如预测"木地板" vs 期望"实木地板"），旧版仅给 0.75 分，经过加权后综合分往往低于 80%，在质量门禁中容易被误判为不合格。

上调目标是：**让语义上合理的预测综合评分稳定在 80% 以上**，同时保持"完全无关"项的低分以保留区分度。

### 1.2 变更范围

仅修改 `similarity.py` 中的数值常量，不涉及算法逻辑、数据结构或函数签名。涉及两项：

| 变更项 | 影响范围 |
|--------|----------|
| `SAME_GROUP_BASE_SIMILARITY` | 1 个常量 |
| `CROSS_GROUP_OVERRIDES` | 23 条跨组特例 |

## 二、变更原则

| 原则 | 说明 |
|------|------|
| **等比例缩放** | 所有跨组特例值统一乘以约 1.20，保留原始相对关系 |
| **不颠覆层次结构** | 同组仍远高于跨组，完全无关仍为 0.0，层次感不变 |
| **最小改动** | 仅改数值，不碰代码结构、注释风格、算法流程 |
| **可回退** | 所有改动集中在一处，`git diff similarity.py` 即可完整审查 |

## 三、核心变更：`SAME_GROUP_BASE_SIMILARITY`

### 3.1 变更前后

| 常量 | v1.0 | v1.1 | 涨幅 |
|------|:----:|:----:|:----:|
| `SAME_GROUP_BASE_SIMILARITY` | 0.75 | **0.85** | +13.3% |

### 3.2 影响分析

这是最关键的变更。它决定了所有"同子类组但名称不同"的评分。以默认权重计算：

```
场景：3 个字段同一子类组 + 1 个字段精确匹配
v1.0: (1.0 x 0.15 + 0.75 x 0.30 + 0.75 x 0.30 + 0.75 x 0.25) / 1.0
    = 0.15 + 0.225 + 0.225 + 0.1875 = 0.7875   < 80%

v1.1: (1.0 x 0.15 + 0.85 x 0.30 + 0.85 x 0.30 + 0.85 x 0.25) / 1.0
    = 0.15 + 0.255 + 0.255 + 0.2125 = 0.8725   > 80%
```

## 六、综合评分示例

沿用 v1.0 报告 §7 的示例场景：预测"木地板" vs 期望"实木地板"（同义词 → 1.0），预测"涂料顶面" vs 期望"石膏板吊顶"（跨组特例）。

```python
name = "客厅_石膏板吊顶_乳胶漆_实木地板.jpg"
data = {
    "space_type": "客厅",
    "wall_material": "乳胶漆",
    "floor_material": "木地板",       # 同义词匹配 -> 1.0
    "ceiling_material": "涂料顶面"    # 石膏板吊顶 vs 涂料顶面 跨组特例
}
```

### 对比

| 版本 | ceiling 分值 | floor 分值 | overall_similarity |
|------|:-----------:|:----------:|:------------------:|
| v1.0 | 0.55 | 1.0 | 0.7825 |
| v1.1 | 0.66 | 1.0 | **0.8555** |

```
v1.1 计算:
  space_type  : 1.0  x 0.15 = 0.15
  ceiling_mat : 0.66 x 0.25 = 0.165
  wall_mat    : 1.0  x 0.30 = 0.30
  floor_mat   : 1.0  x 0.30 = 0.30
  ───────────────────────────────
  overall_similarity = 0.915
```

> 注：同一示例中若墙面材质也落入同组（0.85），则 overall = (1.0 x 0.15 + 0.66 x 0.25 + 0.85 x 0.30 + 1.0 x 0.30) = 0.15 + 0.165 + 0.255 + 0.30 = **0.87**，仍超过 80%。

## 七、集成影响

### 7.1 受影响的调用方

```
+-------------------------------------------------------------------------+
|  /api/vision_test                                                      |
|  +-- evaluate_similarity() -> 使用新阈值，综合分普遍上浮 10-15%          |
+-------------------------------------------------------------------------+
|  benchmark.py / benchmark_runner.py                                    |
|  +-- 同样调用 evaluate_similarity()，模型对比排名不受影响                 |
|     （所有模型同等受益，相对差异不变）                                     |
+-------------------------------------------------------------------------+
|  质量门禁 (quality_gate.sh)                                             |
|  +-- 如果门禁阈值设为 0.80，v1.0 中部分合理预测会误触发阻断；              |
|     v1.1 中同组预测综合分稳超 0.85，门禁误报显著减少                       |
+-------------------------------------------------------------------------+
```

### 7.2 不影响的部分

- `compute_material_similarity()` 算法流程
- `evaluate_similarity()` 权重与加权逻辑
- `get_expect_pretect()` 文件名解析
- `material_library.py` 的枚举与同义词
- 精确匹配（1.0）和完全不匹配（0.0）行为
