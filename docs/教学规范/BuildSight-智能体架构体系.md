## 第一层：基础安全与工程底座

### 1.1 门禁控制智能体
- **定位**：基础安全防线
- **解决问题**：防止文件混合上传（CAD+效果图混装）、防止并发操作（任务中提交新请求）、防止非法文件格式
- **对应标准**：CMMI 技术方案 → 接口安全, PMBOK 风险管理
- **实现**：3道门禁锁（混装409 / 文件格式415/413 / 状态机409）

### 1.2 任务调度智能体
- **定位**：系统任务协调核心
- **解决问题**：管理单图/批量图纸任务排队、串行调度、资源分配，协调各业务智能体有序协作
- **对应标准**：CMMI 项目计划 → 资源分配, PMBOK 进度管理
- **实现**：全局状态机（idle→busy→idle），任务队列

### 1.3 版本&配置管控智能体
- **定位**：配置管理与版本基线
- **解决问题**：管理代码版本（git tag）、配置文件（同义词库、计价模板、系统参数）、多套报价模板，区分测试/演示/正式环境配置
- **对应标准**：CMMI 配置管理, PMBOK 范围管理
- **实现**：Git tag + 配置表（pricing_items / settings）

### 1.4 权限&访问审计智能体
- **定位**：安全管控
- **解决问题**：细化账户权限、操作权限，记录访问与操作行为，区分演示/运维/管理员身份
- **对应标准**：CMMI 过程与产品质量保证, PMBOK 项目相关方管理
- **实现**：操作日志表 + 访问记录

## 第二层：核心业务执行层（9个业务智能体）

### 2.1 CAD解析智能体
- **解决问题**：自动读取DXF图纸，识别房间、面积、周长、墙体类型
- **实现**：`cad_parser.py`，支持LWPOLYLINE和LINE墙体推算
- **价值**：替代人工量房，秒级出量

### 2.2 视觉识别智能体
- **解决问题**：通过大模型识别效果图的墙面/地面/顶面材质
- **实现**：Ollama + qwen2.5vl:latest（1.2s/张，50%严格准确率）
- **价值**：替代肉眼辨别材质，自动输出材质标签

### 2.3 数据融合智能体
- **解决问题**：将CAD工程量与AI识别材质自动关联匹配，含同义词引擎
- **实现**：`/api/data_merge` + `space_synonyms.py`
- **价值**：双线数据自动融合，告别Excel手动合并

### 2.4 报价计算智能体
- **解决问题**：计算工程量×综合单价，累加材质差价、损耗、管理费、税费
- **实现**：融合报价引擎，18项固定系数+12种材质差价规则
- **价值**：自动生成完整报价单

### 2.5 工序管理智能体
- **解决问题**：按工种分组汇总报价明细，生成施工流程图
- **实现**：施工工序模块，支持14个工种管理
- **价值**：报价按工种拆分，方便施工队对接

### 2.6 导出智能体
- **解决问题**：一键生成Excel格式报价单，含分项明细
- **实现**：`/api/export_excel`，openpyxl引擎
- **价值**：交付物可直接用于业务对账

### 2.7 分层工程量智能体
- **解决问题**：按空间维度计算墙面、地面、顶面独立工程量
- **实现**：分层明细模块，墙地比系数自动推算
- **价值**：精确定量到每一面

### 2.8 同义词匹配智能体
- **解决问题**：CAD命名↔AI识别命名的智能映射
- **实现**：`space_synonyms.py`，含30+组同义词+复合词拆分
- **价值**：解决命名不一致导致的匹配失败

### 2.9 材质差价计算智能体
- **解决问题**：根据AI识别的具体材质，自动计算与基础材质的价格差额
- **实现**：12种墙面/地面/顶面材差规则字典
- **价值**：区分材质等级对总价的影响

## 第三层：质量与管控层

### 3.1 全链路核验智能体
- **定位**：自动化端到端质量检查
- **解决问题**：自动执行端到端校验，核对CAD数据、识别结果、报价金额、导出文件一致性
- **对应标准**：CMMI 验证与确认, PMBOK 质量控制
- **核验项**：数据完整性、计算准确性、导出文件格式、响应时间

### 3.2 异常&缺陷管控智能体
- **定位**：缺陷闭环管理
- **解决问题**：统一捕获解析失败、识别超时、计算报错、文件异常等问题，自动分类、记录缺陷、关联场景
- **对应标准**：CMMI 缺陷管理, PMBOK 问题日志
- **实现**：操作日志表 + 异常码体系（4xx/5xx）

### 3.3 基准真值(GT)对标智能体
- **定位**：AI质量量化
- **解决问题**：用客户标准基准图/材质/尺寸做自动比对，量化AI识别准确率、匹配成功率
- **对应标准**：CMMI 度量与分析, PMBOK 数据驱动决策
- **实现**：12张GT效果图基线 + 46项测试用例

### 3.4 操作日志&追溯智能体
- **定位**：全过程可追溯
- **解决问题**：自动记录人工修改（空间名、材质、单价）、系统操作、数据变更，实现全行为可查
- **对应标准**：CMMI 过程追溯, PMBOK 过程资产
- **实现**：`operation_logs` 表 + `trace_json`

## 落地建议

- 权限审计：多角色登录+操作审计
