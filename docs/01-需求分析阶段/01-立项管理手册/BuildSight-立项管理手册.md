## 一、项目背景与立项理由

### 1.1 业务背景

家装行业长期面临以下痛点：

| 痛点 | 描述 | 影响 |
|------|------|------|
| 🎨 **CAD图纸手动算量** | 设计师手工测量CAD图纸中的空间尺寸，逐项计算墙/地/顶面积 | 耗时长（一套图纸约2-4小时），易出错 |
| 🖼️ **效果图材质人工识别** | 装修效果图中的材料（地板、瓷砖、墙漆等）需人工辨认和记录 | 依赖个人经验，识别标准不统一 |
| 📊 **报价依赖人工** | 空间尺寸 + 材质 + 单价 → 逐项人工计算报价 | 效率低，难以批量处理，人力成本高 |
| 📑 **导出格式不统一** | 各家装修公司报价单格式各异，缺乏标准 | 客户对比困难，行业规范化程度低 |

### 1.2 立项理由

BuildSight 项目致力于构建一套"CAD图纸解析 → AI材质识别 → 数据融合 → 自动报价 → Excel导出"的全链路自动化系统，解决上述痛点，实现：

1. **效率提升**：单套图纸报价从 2-4 小时缩短至 5-10 分钟
2. **标准化输出**：统一报价单格式，行业规范化
3. **降低门槛**：减少对人工经验的依赖，降低人力成本
4. **数据沉淀**：积累行业材质-空间-报价数据，持续优化AI模型准确率

### 1.3 可行性分析

| 维度 | 分析结论 |
|------|----------|
| 🛠️ **技术可行性** | FastAPI + Vue3 成熟技术栈，SQLite满足单机需求，Ollama本地大模型可靠运行（qwen2.5:7b 已达92%识别准确率） |
| 💰 **经济可行性** | 1人独立开发，零云服务成本，仅需本地算力（Ollama+GPU） |
| 📋 **操作可行性** | 全流程已在v0.8迭代中验证可行性，从DXF解析到Excel导出的端到端链路已跑通 |
| ⚖️ **法律合规性** | 所有技术栈均为开源/免费授权，无第三方API依赖，CAD解析仅读取不修改原始文件 |

## 三、项目范围

### 3.1 项目描述

BuildSight 是一个**家装智能自动报价系统**，其核心流程为：

```
用户上传
  ├── 📐 DXF图纸 ──→ CAD矢量解析 ──→ 空间/尺寸数据
  └── 🖼️ 效果图  ──→ AI材料识别  ──→ 材质/颜色数据
                            ↓
                      数据融合引擎
                            ↓
                      自动报价计算
                            ↓
                      📊 Excel报价导出
```

### 3.2 项目边界

| 范围类型 | 包含（In Scope） | 不包含（Out of Scope） |
|----------|-------------------|------------------------|
| 🏗️ 系统功能 | DXF解析、AI识别、自动报价、Excel导出 | PDF导出（二期规划） |
| 🧠 AI能力 | 墙/地/顶材质识别、空间类型判别 | 3D建模、渲染生成 |
| 🔧 部署方式 | 本地单机部署 | 云端多租户部署（二期） |
| 📋 模板系统 | 内置标准模板 | 在线模板编辑、自定义单价体系（二期） |
| 🔄 批量处理 | 单套图纸处理 | 多图纸批量处理（二期规划） |
