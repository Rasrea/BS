## 一、项目概述

BuildSight 是一套面向家装行业的 **AI 智能自动报价系统**。系统通过 CAD 图纸矢量解析与 AI 视觉识别技术，自动从施工图中提取空间面积、尺寸等工程量数据，再从效果图中识别墙面/地面/顶面材质，最终结合定价模板自动生成标准化的装修报价单。

### 核心价值

| 维度 | 传统方式 | BuildSight |
|------|---------|------------|
| 图纸解析 | 人工测量、手工计算 | DXF/DWG/PDF 自动解析，秒级出量 |
| 材质识别 | 设计师经验判断 | LLaVA/Qwen2.5-VL 视觉模型自动识别 |
| 报价生成 | Excel 手工编制（小时级） | 数据融合 + 自动计算（分钟级） |
| 报价精度 | 依赖人工经验 | 工程量精准 + 智能同义词匹配 |

## 三、核心业务工作流

系统遵循 **"图纸分析 → 分层明细 → 融合报价 → 施工工序"** 的四步主线：

```
步骤①                              步骤②
┌──────────────────┐         ┌──────────────────────┐
│   图纸分析        │         │   分层明细            │
│                  │         │   空间×面×面积×材质   │
│  CAD上传 ──→ 解析 │         │   （工程量清单）       │
│  效果图上传 ──→ AI│         └──────────┬───────────┘
│  识别             │                    │
└────────┬─────────┘                    ↓
         │                     ┌──────────────────────┐
         │                     │   融合报价            │
         ↓                     │   工程量×单价=金额    │
┌──────────────────┐         │   +材差+损耗+税        │
│  CAD解析结果      │         └──────────┬───────────┘
│  空间列表+面积    │                    │
│                  │                    ↓
│  · 卧室 25.3㎡   │         ┌──────────────────────┐
│  · 客厅 38.7㎡   │         │   施工工序            │
│  · 厨房 12.1㎡   │         │   按工种汇总金额       │
│  ... (106个空间)  │         │   拆除/水电/瓦工/油漆  │
└──────────────────┘         └──────────────────────┘
```

### 3.1 数据流详解

```
CAD 图纸 (.dxf/.dwg/.pdf)
  │
  ├─→ ezdxf 矢量解析 → 空间名称 + 长宽尺寸 + 面积
  │                    (支持 104MB 大图纸，106 个空间精准解析)
  │
  ├─→ PyMuPDF 矢量路径解析 → 空间列表 (PDF 优先路径)
  │
  └─→ 回退：PDF 转图片 → LLaVA 视觉识别

效果图 (.jpg/.png/.webp)
  │
  └─→ 预处理 (缩放/压缩/去EXIF，缩小 80%)
       │
       └─→ Ollama + 视觉模型 → 空间类型 + 墙面/地面/顶面材质

PDF 施工图 (.pdf)
  │
  └─→ PyMuPDF 逐页转图 (2x 缩放)
       │
       └─→ 复用视觉模型 → 每页空间 + 材质信息
```

## 五、关键技术特性

### 5.1 任务状态机

系统采用 **5 态全局锁** 机制，确保同一时间只执行一个任务：

```
状态: idle → cad_running → idle → ai_running → idle → merge_running → idle → export_running → idle
              ↑                                               ↑
         CAD 解析期间锁定                              融合/导出期间锁定
```

- 每个任务类型绑定唯一状态（cad / ai / merge / export）
- `safe_run()` 封装了 acquire → 执行 → release 完整生命周期
- 支持超时熔断（merge 10s / export 15s，CAD 和 AI 不设限）
- 异常时自动 reset 恢复 idle

### 5.2 三层门禁

| 层级 | 检查内容 | 失败 HTTP 码 |
|------|---------|-------------|
| 文件格式/大小 | 扩展名白名单 + 大小上限（CAD 120MB / 图片 10MB / PDF 50MB） | 415 / 413 |
| 混合请求禁止 | 禁止同一请求同时上传 CAD + 图片 | 409 |
| 任务空闲检查 | 系统必须处于 idle 状态才能执行 | 409 |

### 5.3 同义词智能匹配（698 行）

CAD 空间名与 AI 识别空间名的匹配采用 **6 层递进策略**：

```
第1层: 精确匹配       "卧室" == "卧室"
第2层: 子串匹配       "主卧" 包含 "卧室"
第3层: 同义词匹配     "次卧" ↔ "卧室"
第4层: 拼音匹配       "keting" ↔ "客厅"
第5层: 子串+同义      "儿童房" ↔ "小孩卧室"
第6层: 模糊匹配       Levenshtein 距离 ≤ 2
```

### 5.4 视觉模型生态

支持 **16+ 视觉模型**，分为本地 Ollama 模型和云端 DashScope 模型：

| 类型 | 模型 | 特点 |
|------|------|------|
| 本地 | llava:7b | 默认模型，稳定可靠 |
| 本地 | qwen2.5:7b | 中文优化，Benchmark 最优 |
| 本地 | qwen2.5vl:7b | 专用视觉语言模型 |
| 本地 | minicpm-v:latest | LLaVA 替代方案 |
| 云端 | dashscope:qwen3-vl-plus | 千问3 VL Plus |
| 云端 | dashscope:qwen3-vl-flash | 快速模式 |
| 云端 | dashscope:qwen3.7-max | 最强精度 |

### 5.5 报价计算引擎

```
总价 = 基础报价 + 材质差价 + 造型附加 + 损耗 + 管理费 + 税费

基础报价 = Σ(空间面积 × 基础单价 9374)
材质差价 = Σ(墙面/地面/顶面材质溢价 × 系数)
造型附加 = Σ(特殊造型项 × 面积 × 5元)
损耗     = 基础报价 × 损耗率 3%
管理费   = 基础报价 × 管理费率 5%
税费     = (基础报价 + 材质差价 + 损耗 + 管理费) × 税率 3%
```

## 九、关键业务规则

1. **上传互斥** — CAD 图纸与效果图必须分次上传，禁止在同一请求中混合提交
2. **任务串行** — 系统采用全局状态锁，同一时间仅允许一个任务执行
3. **数据融合前提** — 必须同时存在 CAD 解析结果和 AI 识别结果才能执行融合报价
4. **定价全局性** — 定价配置为全局设置，修改后需重新执行融合才生效
5. **PDF 双路径** — PDF 施工图优先走矢量路径解析，矢量为零时自动回退视觉识别
6. **图片预压缩** — 上传效果图自动缩放至 1024px / JPEG 85% 质量 / 去除 EXIF，文件平均缩小 80%
7. **软删除** — 所有删除操作均为逻辑删除（`is_deleted=1`），数据可恢复
