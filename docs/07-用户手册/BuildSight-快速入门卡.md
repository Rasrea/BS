# BuildSight 快速入门卡

> 面向客户培训，打印 / 微信转发用

---

## 🚀 5分钟学会报价

```
┌──────────────────────────────────────────────┐
│                                              │
│  ① 打开浏览器 → http://服务器IP:8100         │
│                                              │
│  ② 点击「图纸分析」                           │
│     ├ 上传 .dxf 图纸 → 自动解析空间面积        │
│     └ 上传 效果图 → AI识别材质（逐张上传）     │
│                                              │
│  ③ 点击「分层明细」→ 核对工程量清单            │
│                                              │
│  ④ 点击「融合报价」→ 查看报价                │
│     └ 点击「导出Excel」→ 下载报价单            │
│                                              │
└──────────────────────────────────────────────┘
```

## 📌 必知规则

| 规则 | 说明 |
|------|------|
| ⛔ 禁止混合上传 | 图纸和效果图不能一起上传 |
| 🔒 任务中请等待 | 按钮变灰说明正在处理 |
| 👀 AI结果需复核 | 材质识别准确率约50%，人工看一遍 |
| ⚙️ 改定价要重新融合 | 配置改完后重新执行融合报价 |

## ❓ 常见卡点

- **没反应？** → 检查服务是否启动（ping localhost:8100）
- **图传错了？** → 去「历史记录」删除重传
- **报价不对？** → 去「分层明细」检查材质和面积
