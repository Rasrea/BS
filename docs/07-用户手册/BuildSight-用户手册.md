## 一、系统概述

BuildSight 是一套**家装智能自动报价系统**，核心能力是：

- 📐 **CAD图纸矢量解析** — 上传DXF图纸，自动识别空间/面积/周长
- 🖼️ **效果图AI材质识别** — 上传效果图，AI自动识别墙面/地面/顶面材质
- 🔗 **双线数据自动融合** — CAD工程量 + AI材质信息 → 一键生成报价
- 📤 **Excel报价导出** — 4张Sheet完整报价单

### 业务流程全景

```
上传CAD图纸 → 自动解析空间面积 → 查看分层工程量清单
                                                            ↓
上传效果图  →  AI识别材质      → 数据融合 → 报价 → 导出Excel
```

## 三、页面功能介绍（按操作顺序）

系统共有 **10个标签页**，按业务流排列：

### ① 📐 图纸分析 — 入口页

**用途**：上传图纸和效果图，启动解析/识别任务。

#### 操作步骤

**CAD图纸上传：**
1. 点击「上传CAD图纸」区域
2. 选择 `.dxf` 格式文件（单次只能上传1张）
3. 确认上传后，系统自动开始解析
4. 等待解析完成（时间视图纸复杂度，约5-30秒）
5. 解析完成后自动显示：空间数量、总面积、各房间面积

**效果图上传：**
1. 点击「上传效果图」区域
2. 选择 `.jpg/.png/.webp` 图片文件（单次1张）
3. 系统自动调用AI识别材质
4. 识别完成后显示：空间类型、墙面材质、地面材质、顶面材质、装修风格

> ⚠️ **重要规则**：CAD和效果图必须**分开上传**，禁止混合在一个请求中。

---

### ② 📋 分层明细 — 工程量清单

**用途**：查看每个房间的精细化工程量。

每行显示：
- 空间名称（如：客厅、主卧、厨房）
- 施工面（墙面 / 地面 / 顶面）
- 面积（㎡，精确到0.1）
- 材质（手工可修改）
- 施工范围描述

> 💡 **提示**：材质列支持手动编辑，修改后点击保存即可更新。

---

### ③ 💰 融合报价 — 核心报价页

**用途**：将CAD工程量与AI材质数据融合，生成最终报价。

#### 操作步骤

1. 确保已同时完成CAD解析和AI识别
2. 在「选择融合数据」下拉框中，选择要融合的图纸和识别结果
3. 系统自动计算：
   - **基础价** = 各空间工程量 × 单价
   - **材质差价** = AI识别材质与基准材质的差价
   - **管理费** = 基础价 × 管理费率
   - **税金** = (基础价 + 材质差价 + 管理费) × 税率
4. 展示报价汇总：总金额、各分项金额
5. 可手动调整工程量或材质，调整后实时重算

> 💡 **提示**：下拉框默认显示最新的3条数据，自动选中最新一条。

---

### ④ 🔧 施工工序 — 工种汇总

**用途**：按工种展示报价构成。

10个标准工种：
1. 拆除工程
2. 水电工程
3. 防水工程
4. 瓦工工程
5. 木工工程
6. 油漆工程
7. 安装工程
8. 保洁工程
9. 管理费
10. 税金

每个工种展示：涉及的空间、工程量、单价、小计金额。

---

### ⑤ 📊 标准报价 — 三表合一

**用途**：汇总展示三张标准报价表。

- **综合汇总表**：按空间汇总总价
- **空间分项表**：按空间×施工面展示单价×数量
- **工序费用表**：按工种汇总报价

---

### ⑥ 📋 历史记录 — 数据管理

**用途**：查看和管理所有历史数据。

功能列表：
- 查看历史CAD解析记录
- 查看历史AI识别记录
- 查看历史融合报价记录
- 删除不需要的记录
- 一键导出Excel报价单

---

### ⑦ 📋 双源核对 — 数据校验

**用途**：比对CAD数据和AI识别数据的一致性。

- 空间名称匹配检查
- 数据完整性检查
- 异常数据标记

---

### ⑧ ⚙️ 定价配置 — 全局设置

**用途**：配置报价模板的参数。

可配置项：
| 参数 | 说明 | 默认值 |
|------|------|--------|
| 管理费率 | 按基础价的百分比 | 8% |
| 税率 | 按(基础价+材质差价+管理费)的百分比 | 3% |
| 损耗率 | 按工程量的百分比 | 5% |
| 洞口扣减比例 | 门窗洞口扣减面积比例 | 50% |
| 各材质单价 | 每平方米报价 | 按材质类型 |
| 材质差价系数 | AI识别材质相对于基准材质的差价系数 | 按材质类型 |

> ⚠️ **注意**：定价配置为**全局设置**，修改后需重新执行融合报价才能生效。

---

### ⑨ 📝 操作日志 — 审计追踪

**用途**：记录所有系统操作，便于问题排查和数据溯源。

记录内容包括：
- 操作时间
- 操作类型（上传/解析/识别/融合/导出）
- 操作人
- 操作结果（成功/失败及原因）

---

### ⑩ 🔬 识别测试 — 模型评估

**用途**：批量测试视觉模型的材质识别准确率。

操作步骤：
1. 选择测试图片（支持批量多选）
2. 输入预期的材质标签
3. 点击「开始测试」
4. 系统自动识别并对比预期结果，输出准确率统计

## 四、核心工作流（完整示例）

以下是一个完整的报价流程示例：

### 场景：12房间住宅报价

```
第1步：上传CAD图纸（DXF）
  ├─ 系统自动解析 → 输出12个房间 + 面积 + 工程量
  └─ 在「图纸分析」页查看结果

第2步：上传12张效果图（逐个上传）
  ├─ 每张图AI识别 → 输出空间类型 + 墙面/地面/顶面材质
  └─ 在「图纸分析」页查看每张识别结果

第3步：打开「分层明细」页
  └─ 查看每个房间的工程量清单，核对材质信息

第4步：打开「融合报价」页
  ├─ 选择要融合的数据
  └─ 系统自动生成报价：¥112,784（示例）

第5步：打开「施工工序」页
  └─ 按10个工种查看报价构成

第6步：回到「融合报价」页
  └─ 点击「导出Excel」→ 下载4Sheet报价单
```

**全程耗时**：约2-5分钟（不含图片上传时间）

## 五、常见问题（FAQ）

### Q1: 为什么上传CAD后没有解析结果？
- 确认文件格式为 `.dxf`
- 确认图纸中包含可识别的空间多边形
- 检查后端服务是否正常运行（浏览器访问 `http://localhost:8100/api/health`）

### Q2: 为什么AI识别结果不准确？
- 当前默认模型准确率约50%，**人工核验和修正是必要环节**
- 可以切换到备用模型（在识别测试页切换）
- 图片清晰度、拍摄角度都会影响识别效果

### Q3: 为什么融合报价页没有数据？
- 需要**同时存在**CAD解析结果和AI识别结果
- 确认已完成至少一次CAD解析和一次AI识别
- 检查下拉框是否选对了数据记录

### Q4: 修改定价配置后，报价为什么没变？
- 定价配置为**全局设置**，修改后必须**重新执行融合报价**才生效

### Q5: 可以一次上传多张CAD图纸吗？
- 首期版本**仅支持单张处理**，多图纸批量处理规划在二期

### Q6: 上传后按钮变灰点不了怎么办？
- 系统正在执行任务，等待当前任务完成即可
- 这是系统的**防并发保护机制**，避免数据冲突

### Q7: 支持哪些效果图格式？
- 支持 `jpg`、`png`、`webp` 格式
- 建议图片清晰度：不低于 800×600 像素

### Q8: 如何导出报价单？
- 在「融合报价」页点击「导出Excel」按钮
- 导出的Excel包含4张Sheet：报价汇总、空间分项、工序费用、材质明细

## 六、注意事项与最佳实践

### ✅ 推荐操作顺序
```
CAD上传解析 → 效果图逐张上传识别 → 核对分层明细 → 融合报价 → 导出
```

### ❌ 禁止操作
- 同一请求中混合上传图纸+效果图
- 任务进行中刷新页面（等待完成即可）
- 多个用户同时操作同一系统（全局锁保护，但建议排队使用）

### 💡 效率技巧
- AI识别结果**建议人工复核**，修正后保存
- 定价配置**一次配好，多次使用**
- 使用「识别测试」页选择准确率更高的模型
