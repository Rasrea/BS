# 门禁规范

## 1. 任务状态机

5种互斥状态，`asyncio.Lock` 保护：

```
idle ──→ cad_running ──→ idle
     ──→ ai_running  ──→ idle
     ──→ merge_running─→ idle
     ──→ export_running→ idle
```

**规则**：
- 仅 `idle` 可接受新任务
- 每种任务类型对应一种锁状态
- 前端按钮互斥：任务中全部置灰
- 异常退出通过 `task_state.reset()` 强制释放

## 2. 文件门禁

| 类型 | 允许格式 | 最大大小 |
|------|---------|---------|
| CAD | .dxf, .dwg | 120MB |
| 图片 | .jpg, .jpeg, .png, .webp, .bmp | 10MB |

## 3. 混装门禁

**禁止** 同一请求同时携带CAD `+` 图片，必须分两次单独调用。

## 4. 超时熔断

| 任务类型 | 超时阈值 | 执行方式 |
|---------|---------|---------|
| CAD解析 | 30s | ProcessPoolExecutor（可强杀） |
| AI识别 | 120s | ThreadPoolExecutor |
| 数据融合 | 10s | ThreadPoolExecutor |
| Excel导出 | 15s | ThreadPoolExecutor |

超时 → 自动释放锁 → 返回504 → 前端提示+重试入口

## 5. 前端互斥

- 任务中：全部操作按钮置灰 + 禁用
- 队列模式：逐张串行，不破坏后端互斥锁
- 状态栏实时显示 `idle / cad_running / ai_running`
