# BuildSight 模型视觉识别 Benchmark 基准规范

> 版本: v1.0 · 最后更新: 2026-06-13
> 用途: 模型选型、回归门禁、上线准入标准
> 测试环境: Ollama 本地部署 · 单卡 RTX 3090 (24GB)

---

## 一、目的与适用范围

### 1.1 目的
建立标准化、可复现的视觉识别模型评测流程，作为：
- **模型选型依据**：新增/切换模型前必须跑此基准
- **回归门禁**：prompt调整、引擎升级、部署变更后必须验证不低于基线指标
- **版本对比**：每次评测结果归档，追溯模型效果变化

### 1.2 适用范围
所有用于效果图/施工图空间材质结构化识别的Vision Language模型，包括但不限于：
- LLaVA 系列
- Qwen-VL 系列
- 后续接入的任何VL模型（DeepSeek-VL、GLM-4V 等）

## 三、测试流程（执行标准）

### 3.1 前置条件
- Ollama 服务运行正常（`ollama list` 返回目标模型）
- 后端服务不要求运行（benchmark 独立运行，不影响线上）
- 磁盘有 1GB 以上空闲空间

### 3.2 执行步骤

```bash
# 激活环境
source /home/sd317/miniconda3_new/etc/profile.d/conda.sh
conda activate torchtest

# 运行基准测试（自动输出三模型对比）
cd /home/sd317/cad
python3 docs/03-规范/benchmark_runner.py
```

### 3.3 输出内容
脚本输出包含：
1. 每个模型 × 每张图的逐项识别结果
2. 字段填充率（4字段中的填充比例）
3. 平均响应时间
4. 综合评分排序

### 3.4 自动化门禁规则

| 门禁项 | 阈值 | 触发动作 |
|--------|------|----------|
| 字段填充率 | ≥ 90% | 低于阈值禁止部署 |
| 单图识别耗时 | ≤ 10s | 超过阈值发出性能警告 |
| 空间识别准确率 | ≥ 80% (人工判定) | 低于阈值回退默认模型 |
| 测试集完整性 | 3张图片全部存在 | 缺失则中止评测 |

## 四、基准评测脚本

文件：`docs/03-规范/benchmark_runner.py`

### 4.1 核心功能
- 自动枚举待测模型列表
- 调用 `image_recognizer.recognize_image()` 逐一识别
- 统计字段填充率、响应时间、空间识别一致性
- 输出 Markdown 格式报告
- 支持 `--model` 参数指定单一模型快速验证

### 4.2 使用方法

```bash
# 全量三模型对比（默认）
python3 docs/03-规范/benchmark_runner.py

# 单模型快速验证
python3 docs/03-规范/benchmark_runner.py --model qwen2.5:7b

# 输出到文件
python3 docs/03-规范/benchmark_runner.py > benchmark_result_$(date +%Y%m%d).md
```

## 六、变更与归档规则

### 6.1 触发重新评测的场景
| 场景 | 必须重新跑基准 | 备注 |
|------|---------------|------|
| 新增VL模型 | ✅ | 加入对比矩阵 |
| 修改 Prompt/结构化格式 | ✅ | 验证格式兼容性 |
| Ollama 版本升级 | ✅ | 验证推理质量 |
| 更换硬件（GPU） | ✅ | 验证性能基线 |
| 仅前后端功能迭代 | ❌ | 不涉及模型调用 |

### 6.2 报告归档
- 每次评测结果保存至 `docs/03-规范/benchmark_reports/`
- 文件命名：`benchmark_YYYYMMDD_HHMMSS.md`
- 脚本运行自动生成报告，无需手动整理

### 6.3 准入门禁
**上线/合并前必须满足以下全部条件：**
1. ✅ 字段填充率 ≥ 90%
2. ✅ 平均单图耗时 ≤ 10s
3. ✅ 测试集3张图片完整存在
4. ✅ 无模型引起的服务崩溃
