# 五层门禁规范 v2.0

## 概述

系统采用 **5层门禁** 保障操作安全，从前端到后端形成完整防护链：

```
用户操作 → ①前端互斥 → ②混装门禁 → ③文件门禁 → ④状态机锁 → ⑤超时熔断
```

---

## 第一层：前端互斥（UI层）

**位置**：`frontend/src/App.vue`

| 规则 | 实现 |
|------|------|
| 任务执行中，全部操作按钮置灰 + 禁用 | `:disabled="loading"` |
| 禁止重复提交 | loading锁 |
| 状态栏实时显示 `idle / cad_running / ai_running` | `sysStatus.task_state` |
| 队列模式逐张串行 | ImageQueue.vue 串行队列 |

---

## 第二层：混装门禁（API层）

**位置**：`backend/main.py` → `check_mixed_request()`

**规则**：禁止同一请求同时携带CAD + 图片，必须分两次单独调用。

```python
def check_mixed_request(cad_file, image_file):
    if cad_file and image_file:
        raise HTTPException(409, "禁止混合请求")
```

**返回**：`409 Conflict`

---

## 第三层：文件门禁（API层）

**位置**：`backend/main.py` → `check_file_gate()`

| 类型 | 允许格式 | 最大大小 |
|------|---------|---------|
| CAD | .dxf, .dwg | 120MB |
| 图片 | .jpg, .jpeg, .png, .webp, .bmp | 10MB |
| PDF | .pdf | 50MB |

**返回**：`415 Unsupported Media Type` / `413 Payload Too Large`

---

## 第四层：状态机锁（核心层）

**位置**：`backend/main.py` → `class TaskState`

**5种互斥状态**，`asyncio.Lock` 保护：

```
idle ──→ cad_running ──→ idle
     ──→ ai_running  ──→ idle
     ──→ merge_running ──→ idle
     ──→ export_running ──→ idle
```

**核心规则**：
- 仅 `idle` 可接受新任务（`require_idle()`）
- 每种任务类型对应一种锁状态，互不冲突
- 异常退出通过 `task_state.reset()` 强制释放
- 拒绝返回 `409 Conflict`

```python
async def require_idle(task_type):
    ok_flag, tid = await task_state.acquire(task_type)
    if not ok_flag:
        raise HTTPException(409, f"系统当前有任务正在执行（{task_state.state}）")
    return tid
```

---

## 第五层：超时熔断（安全层）

**位置**：`backend/main.py` → `safe_run()`

**说明**：`timeout=0` 表示不设超时（适配CPU笔记本慢速推理）。

| 任务类型 | 超时阈值 | 当前值 | 执行方式 |
|---------|---------|--------|---------|
| CAD解析 | TIMEOUT_CAD | **0（不超时）** | ProcessPoolExecutor（可强杀） |
| AI识别 | TIMEOUT_AI | **0（不超时）** | ThreadPoolExecutor |
| 数据融合 | TIMEOUT_MERGE | 10s | ThreadPoolExecutor |
| Excel导出 | TIMEOUT_EXPORT | 15s | ThreadPoolExecutor |

**超时机制**：
```
timeout > 0 → asyncio.wait_for(fut, timeout=timeout)
timeout = 0 → asyncio.wait_for(fut, timeout=None)  # 不超时
```

**超时返回**：`504 Gateway Timeout` → 自动释放锁

## 门禁拦截统计

| 门禁层 | 触发条件 | HTTP状态码 | 触发频率 |
|--------|---------|-----------|---------|
| ①前端互斥 | 任务中点击按钮 | 浏览器拦截 | 高频 |
| ②混装门禁 | CAD+图片同请求 | 409 | 极少 |
| ③文件门禁 | 格式/大小不合法 | 415/413 | 低 |
| ④状态机锁 | 非idle时请求任务 | 409 | 中 |
| ⑤超时熔断 | 任务执行超时 | 504 | 低（取消超时后极少） |
