## 数据流

### 主流程（端到端）

```
DXF上传 → CAD解析(106空间) → 分层工程量(墙/地/顶)
                                              ↓
效果图上传 → LLaVA结构化识别 → 材质入库(space_type/wall/floor/ceiling)
                                              ↓
                          按「空间名+部位」自动匹配
                                              ↓
                        数据融合 → 报价计算 → Excel导出
                                              ↓
                        工序汇总 → 工序×空间对照表
```

### 两条独立数据线

```
CAD线: DXF → 矢量解析 → 106空间(面积/周长/长宽) → 分层工程量(detail_json)
AI线:  效果图 → LLaVA → 结构化JSON(space_type+三面材质) → image_analysis_results
                              ↓
                     最终在融合报价交汇
```

## 三层门禁

1. **文件门禁**：格式(.dxf/.dwg/.jpg/.png) + 大小(CAD 120MB / 图片 10MB)
2. **混装门禁**：禁止同一请求同时携带CAD+图片
3. **忙状态门禁**：5种状态，仅idle可执行，占用对应锁

## 任务状态机

```
idle → cad_running → idle
idle → ai_running → idle
idle → merge_running → idle
idle → export_running → idle
```
