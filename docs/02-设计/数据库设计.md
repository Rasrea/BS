# 数据库设计

## ER 概览

7张表，SQLite，JSON字段用于结构化数据存储。

```
drawing_records 1──N cad_analysis_results 1──N quote_records
                                                │
image_analysis_results ─────────────────────────┘
                                              
system_settings (独立，键值对)
operation_logs (独立，审计)
construction_processes (独立，工序模板)
```

## 表结构

### 1. drawing_records（图纸记录）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| filename | TEXT | 原始文件名 |
| file_path | TEXT | 服务器存储路径 |
| file_size | INTEGER | 文件大小(bytes) |
| file_hash | TEXT | 文件哈希（预留） |
| upload_time | TEXT | 上传时间 |
| parse_status | TEXT | pending/completed/error |
| cad_result_json | TEXT(JSON) | 解析结果摘要 {spaces_count, total_area} |
| is_deleted | INTEGER | 软删除 |

### 2. cad_analysis_results（CAD解析结果）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| drawing_id | INTEGER FK | → drawing_records |
| space_name | TEXT | 空间名称 |
| length | REAL | 边界框长度(m) |
| width | REAL | 边界框宽度(m) |
| height | REAL | 层高(默认2.8m) |
| area | REAL | 空间面积(㎡) |
| base_quantity | TEXT(JSON) | 基础工程量（预留） |
| base_price | REAL | 基础报价 |
| rule_version | TEXT | 计价规则版本 |
| **detail_json** | **TEXT(JSON)** | **分层数据+材质绑定** |
| is_deleted | INTEGER | 软删除 |

> **detail_json 结构**：
> ```json
> {
>   "surface_breakdown": {
>     "surfaces": {
>       "floor": {"area": 20.5, "unit": "㎡", "material": ""},
>       "wall": {"area": 45.2, "net_area": 38.4, "unit": "㎡", "deduct_ratio": 0.15, "material": ""},
>       "ceiling": {"area": 20.5, "unit": "㎡", "material": ""}
>     },
>     "perimeter_m": 12.5,
>     "height_m": 2.8
>   },
>   "surface_materials": {
>     "floor": {"name": "木地板", "code": "FL001", "bound_at": "..."},
>     "wall": {"name": "乳胶漆", "code": "WL001", "bound_at": "..."}
>   }
> }
> ```

### 3. image_analysis_results（效果图识别）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| drawing_id | INTEGER | 关联图纸(0=未关联) |
| image_path | TEXT | 图片存储路径 |
| **recognized_space** | **TEXT** | **识别空间（如客厅）** |
| **material_info** | **TEXT(JSON)** | **结构化材质数据** |
| confidence | REAL | 置信度 |
| confirm_status | TEXT | unconfirmed/confirmed |
| manual_correction | TEXT | 人工修正文本 |
| manual_correction_json | TEXT(JSON) | 人工修正JSON |
| is_deleted | INTEGER | 软删除 |

> **material_info v2.0 结构**：
> ```json
> {
>   "wall": "乳胶漆",
>   "floor": "木地板",
>   "ceiling": "石膏板吊顶",
>   "style": "现代简约",
>   "remark": "背景墙为木饰面",
>   "model_used": "llava:7b"
> }
> ```

### 4. quote_records（报价汇总）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| cad_result_id | INTEGER | |
| image_result_ids | TEXT(JSON) | 用到的识别结果ID列表 |
| base_price | REAL | 基础报价 |
| material_diff_price | REAL | 材质差价 |
| loss_price | REAL | 损耗 |
| manage_fee | REAL | 管理费 |
| tax_fee | REAL | 税费 |
| final_price | REAL | 最终总价 |
| quote_detail_json | TEXT(JSON) | 分项明细（含process_id） |
| trace_json | TEXT(JSON) | 链路追踪 |
| is_deleted | INTEGER | 软删除 |

### 5. construction_processes（施工工序）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| name | TEXT | 工序名称 |
| sort_order | INTEGER | 排序 |
| work_type | TEXT | 工种分类 |
| standard_days | REAL | 标准工期(天) |
| color | TEXT | 流程图颜色 |
| is_deleted | INTEGER | 软删除 |

内置10项：拆除/水电/防水/瓦工/木工/油漆/安装/保洁/竣工/软装

### 6. system_settings（系统配置）

键值对设计，当前约25项配置，涵盖：
- 定价类：base_unit_price, manage_fee_rate, tax_rate, loss_rate
- 扣减类：deduct_door_window, deduct_wc_kitchen, perimeter_factor
- **模型类：active_vl_model**

### 7. operation_logs（操作日志）

审计日志，记录每次任务执行+模型切换等管理操作。
