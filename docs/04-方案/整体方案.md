# 家装智能自动报价系统 — 整体落地推进方案

## 一、核心结论

**现阶段核心难点 = 精准识别 + 图文数据精准对接**
**后期报价单、自定义模板、自定义单价 = 工程实现类工作，技术难度低、易落地**

### 整体优先级

| 优先级 | 内容 | 定位 |
|--------|------|------|
| 🔴 P0 | AI精准识别优化 + 效果图 ↔ CAD 数据精准关联 | **核心攻坚，决定系统可用性** |
| 🟠 P1 | 标准工序库、基础单价体系搭建 | 基础配套 |
| 🟡 P2 | 自定义报价模板、自定义单价、多版式导出 | 灵活拓展 |

---

## 二、核心难点 & 分步解决方案

### 难点1：提升AI识别精准度

**现状**：llava:7b 已改为固定JSON输出，但材质/造型识别精度不足，
部分效果图无法区分墙/地/顶，复杂吊顶、厨卫材料易出错。

#### 分层优化方案

**短期优化（立即执行，零架构改动）**
- 固化行业提示词，强化墙/地/顶分区、材质、造型、空间识别
- 人工复核标记：修正结果作为样本
- 图片预处理：统一尺寸、压缩画质

**中期升级（精度不足时切换模型）**
- 常规演示 → `llava:7b`（资源低、稳定）
- 高精度需求 → `qwen2.5:7b`（中文优化）
- 识别异常 → 标记「待人工核对」，不阻断流程

**长期（二期）**
- 对接云端视觉模型故障兜底

### 难点2：效果图 ↔ CAD 分层数据精准对接

**现状**：CAD已拆分独立空间+墙/地/顶分层工程量；
AI已输出结构化数据；但二者尚未自动精准绑定。

#### 三级自动匹配规则

1. **精准名称匹配**：空间名完全一致，直接自动绑定
2. **同义词模糊匹配**：起居室=客厅、主卧=主卧室等，解决命名不一致
3. **人工手动绑定（兜底）**：前端可视化绑定面板

#### 数据流转闭环

```
效果图上传 → 结构化材质入库 → 系统按「空间+部位」匹配CAD工程量
→ 匹配成功 → 自动进入报价计算链路
```

## 三、报价单 & 自定义模板/单价

### 整体思路

「基础模板 + 自定义配置」模式：
1. 系统内置官方标准模板
2. 支持用户上传/在线编辑自定义模板
3. 单价、扣减系数、管理费、税费、工序全部可视化自定义

### 模块拆分

| 模块 | 内容 | 难度 |
|------|------|------|
| 单价体系 | 按空间+部位+材质+工序设定独立单价 | 低 |
| 工序联动 | 材质+部位绑定工序，用户可调序调价 | 低 |
| 模板管理 | 在线版式编辑 + Excel外部模板导入 | 中 |
| 报价生成 | 自动填充数据 → 预览 → Excel/PDF导出 | 低 |

### 模板方案

**方案A：在线版式编辑** — 内置多套预设模板，支持增删列、调顺序
**方案B：Excel模板导入** — 上传公司现有报价表，配置字段映射，零学习成本
