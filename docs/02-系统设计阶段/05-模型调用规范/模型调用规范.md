# 视觉模型调用规范

## 调用方式

通过 Ollama 本地部署，`/api/chat` 接口：

```bash
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5:7b",
    "messages": [{
      "role": "user",
      "content": "结构化Prompt...",
      "images": ["base64图片"]
    }],
    "stream": false
  }'
```

## 结构化 Prompt（v2.0）

强制JSON输出6字段，禁止多余文字：

```json
{
  "space_type": "客厅",
  "wall_material": "乳胶漆",
  "floor_material": "木地板",
  "ceiling_material": "石膏板吊顶",
  "decor_style": "现代简约",
  "remark": "背景墙木饰面"
}
```

## 三层模型策略

| 方案 | 模型 | 切换方式 | 场景 |
|------|------|---------|------|
| 🟢 默认 | `qwen2.5:7b` | 🏠首页模型选择器 | 常规演示，稳定优先（基准测试92%准确率） |
| 🟡 精度 | `llava:7b` | ⚙️定价后台下拉切换 | 细分材质识别、复杂造型 |
| 🔴 兜底 | 云端视觉模型 | 二期实现 | 本地故障时自动降级 |

## 规则约束

1. **单图同步调用**：禁止多张图并发请求
2. **受全局任务锁管控**：与CAD解析、数据融合互斥
3. **超时120s**：超时标记识别异常，前端支持重试
4. **JSON解析容错**：5层降级，全部失败标记「待人工核对」
5. **模型切换记录**：写入 `operation_logs`

## 图片预处理建议

- 统一尺寸：最长边 ≤ 1024px
- JPEG压缩质量85
- 剔除无关元素（水印、边框、文字叠加）
