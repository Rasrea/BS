## 一、项目概述

### 1.1 项目背景

家装行业长期面临 **CAD 图纸手动算量耗时**（2-4 小时/套）、**效果图材质依赖人工经验**、**报价标准化程度低** 三大痛点。BuildSight 项目致力于构建一套从 CAD 图纸 + 装修效果图到 Excel 报价单的全自动转换系统，实现家装报价的智能化、标准化、高效化。

### 1.2 项目目标回顾

| 目标 | 目标值 | 实际达成 | 结果 |
|------|:------:|:--------:|:----:|
| DXF 图纸矢量解析空间识别率 | ≥ 98% | ✅ 106 空间识别 | 达成 |
| AI 材质识别准确率 | ≥ 85% | ✅ **92%** | **超额 +7%** |
| 端到端处理时间 | ≤ 10 分钟/套 | ✅ < 5 分钟 | 达成 |
| Excel 导出规范完整度 | 4 Sheet | ✅ 4 Sheet | 达成 |
| CAD+AI 自动匹配成功率 | ≥ 85% | ✅ 三级匹配全覆盖 | 达成 |
| 施工工序模板覆盖 | ≥ 10 项 | ✅ 10 项标准工序 | 达成 |
| 支持的视觉模型数 | ≥ 2 种 | ✅ 3 种 | 达成 |

### 4.3 Harness 视觉识别架构

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  全图推理  │ →  │  类型校验  │ →  │  规则校验  │ →  │  裁剪重试  │ →  │  输出     │
│(Inferrer) │    │(Validator)│    │(Validator)│    │(Retry)   │    │(Result)  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
                     ↑ 发现触发条件   ↑ 发现规则冲突
                     │
              ┌──────┴──────┐
              │ 透视裁剪分区  │
              │ ceiling 0-30%│
              │ wall  25-75% │
              │ floor 60-100%│
              └─────────────┘
```

**架构特点：**
- **阶段单一职责**：每个阶段可独立替换
- **标准接口通信**：阶段间通过 dict 交互
- **全局 Hook 拦截**：日志/指标统一采集
- **中心化配置**：所有参数集中在 config.py

## 七、经验与教训

### 7.1 成功经验

#### 🏆 1. Harness 架构设计是最大成功因素

初始裸调 LLaVA 仅 16.7% 准确率。通过设计 **5 阶段流水线架构**（裁剪→推理→校验→重试→输出），将视觉模型调用系统化、工程化，准确率跃升至 92%。

**关键设计原则：**
- 每个阶段单一职责，可独立替换
- 校验失败自动触发裁剪重试
- 枚举约束限制模型输出空间
- 规则引擎做语义合理化

#### 🏆 2. 需求优先级分层策略有效

采用 **P0/P1/P2** 三层优先级管理，确保核心链路优先交付：
- P0：AI 识别 + CAD 解析 + 融合报价（核心可用性）
- P1：工序模板 + 导出 + 配置（基础配套）
- P2：自定义模板 + 单价体系 + PDF（灵活拓展）

#### 🏆 3. Benchmark 驱动开发模式

建立标准化评测流程，每次模型变更后运行 Benchmark，量化追踪准确率演进。避免了"凭感觉调参"的盲目优化。

#### 🏆 4. 三级门禁保障系统健壮性

文件格式校验 + 混装拦截 + 状态机互斥 + 超时熔断，四道防线确保系统不会因异常输入或并发操作而崩溃。

#### 🏆 5. 单人开发的聚焦策略

1 人独立开发时，严格聚焦核心链路，非核心功能标记为 P1/P2 后移，避免范围蔓延。

### 7.2 改进空间

#### 🔧 1. 基准测试集需要扩充

当前 3 张标准效果图偏少，建议扩充至 20+ 张，覆盖更多空间类型和装修风格，提高 Benchmark 统计可信度。

#### 🔧 2. 同义词库需持续完善

当前 26 组同义词映射已覆盖常见场景，但不同地区/设计师对空间命名习惯差异大，建议持续推进社区贡献。

#### 🔧 3. 图片预处理可进一步优化

统一尺寸、压缩画质、剔除水印边框等 P1 优化项尚未实施，预计实施后可进一步提升识别准确率 3-5%。

#### 🔧 4. 人工复核样本积累

AI 识别结果人工修正后作为训练样本的机制尚未建立，建议后续建立闭环，持续提升模型准确率。

#### 🔧 5. 自动化测试覆盖不足

当前测试以手动 E2E + Benchmark 为主，缺乏单元测试和集成测试自动化套件。
