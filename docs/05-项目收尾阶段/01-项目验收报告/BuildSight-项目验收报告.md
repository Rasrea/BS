## 一、验收概述

### 1.1 项目简介

BuildSight 是一套从 **CAD 图纸 + 装修效果图** 到 **Excel 报价单** 的全自动转换系统，实现家装报价的智能化、标准化、高效化。

**核心业务流程：**

```
📐 DXF/DWG图纸 ──→ CAD矢量解析 ──→ 空间/尺寸/工程量数据
🖼️ 装修效果图  ──→ Harness AI材质识别 ──→ 墙/地/顶材质/风格
                              ↓
                        数据融合引擎（三级匹配）
                              ↓
                        自动报价计算（四层公式）
                              ↓
                        📊 Excel导出（4Sheet）
```

## 六、门禁验收结果

### 6.1 三层门禁架构

```
第一层: 文件门禁（格式校验 + 大小校验）
  ├── 支持格式: .dxf / .dwg / .jpg / .jpeg / .png / .pdf
  ├── CAD 上限: 120MB
  ├── 图片上限: 10MB
  └── PDF 上限: 50MB

第二层: 混装门禁 + 状态机互斥
  ├── 禁止同一请求同时携带 CAD + 图片 (409)
  ├── 5 种互斥状态: idle / cad_running / ai_running / merge_running / export_running
  └── asyncio.Lock 确保单任务运行

第三层: 超时熔断
  ├── CAD 解析: 不限时（ProcessPoolExecutor）
  ├── AI 识别: 不限时（适配 CPU 笔记本）
  ├── 数据融合: 10 秒
  └── Excel 导出: 15 秒
```
