## 一、行业痛点

家装行业的报价环节长期面临以下困境：

**📐 图纸算量全靠人工**
设计师拿到 CAD 施工图后，需要手动测量每个空间的面积、周长、尺寸，逐一填写工程量清单。一套 100㎡ 的户型涉及 10+ 个空间、20+ 项工程量，人工计算耗时 2-3 小时且极易出错。

**🎨 效果图材质靠经验判断**
客户看到的效果图只展示最终效果，但墙面用的乳胶漆还是墙纸？地面是瓷砖还是木地板？全靠人工根据经验识别和记录，标准不统一，经常与施工实际不符。

**📊 报价编制流程割裂**
工程量计算、材质确认、报价编制三个环节分属不同人员或不同系统，数据需要反复手工转录和核对，一次报价全流程通常需要 1-3 天。

**❌ 多头修改难以追溯**
客户变更需求、设计师修改方案、供应商调整价格——每次变更都需要从头算一遍，历史版本难以追踪，报价误差频频发生。

---

## 二、解决方案

BuildSight 是一套**端到端智能家装报价系统**，将 CAD 图纸解析、AI 视觉识别、数据融合与自动报价整合为一条自动化流水线。

### 系统核心理念

```
上传CAD图纸 ──→ 自动解析 ──→ 生成工程量
     ↓
上传效果图 ──→ AI识别材质 ──→ 确定装修标准
     ↓
一键融合 ──→ 自动报价 ──→ 导出报价单
```

**全程无需人工算量、无需人工判断材质、无需手工编制表格。**

### 适用对象

| 群体 | 解决的问题 |
|------|-----------|
| **家装公司** | 快速出报价、减少人工成本、统一报价标准 |
| **独立设计师** | 从繁琐的算量工作中解放，专注设计本身 |
| **施工队/工长** | 精准的工程量清单，减少材料浪费和漏项 |
| **装修业主** | 透明清晰的报价明细，知道钱花在哪里 |
| **教学实训** | 可作为智能建造相关课程的案例教学平台 |

## 三、核心功能

### 🏗️ 1. 智能图纸解析

- **支持格式**：DXF、DWG、PDF 施工图，自动识别无需标注
- **解析能力**：单张图纸解析 106 个空间、近 1000㎡ 面积
- **输出内容**：每个空间的名称、面积、周长、长宽尺寸
- **技术特点**：矢量路径精确提取，毫米级精度

### 🧠 2. AI 视觉材质识别

- **识别对象**：室内效果图（客厅、卧室、厨房、卫生间等）
- **识别内容**：墙面材质、地面材质、吊顶材质、软装搭配
- **本地运行**：不依赖云端 API，数据不出本地，无需联网
- **模型可选**：qwen2.5vl（推荐）或 LLaVA，一键切换

### 🔗 3. 数据智能融合

- **自动匹配**：CAD 空间名与 AI 识别结果自动建立关联
- **同义词引擎**：内置空间名智能匹配（如"大厅"→"客厅"、"卧室"→"次卧"）
- **手动兜底**：自动匹配失败时可人工绑定，灵活兜底
- **修改可追溯**：所有人工修改记录入库，支持审计溯源

### 💰 4. 自动报价计算

- **计价模型**：基础工程量价 + AI 材质差价 + 损耗 + 管理费 + 税费
- **多套模板**：支持标准型、经济型等多套报价模板
- **灵活配置**：费率、损耗率、扣减系数均可可视化调整
- **精细分级**：支持按空间→墙面/地面/顶面→施工工序三级报价

### 📄 5. 一键导出报价单

- **导出格式**：专业 Excel 报价单，4 个工作表
- **内容完整**：报价总表、分项明细、工程量清单、材质清单
- **工序报价**：可选精细化工序报价版本，按墙/顶/地分列

### 🛡️ 6. 系统安全与稳定

- **任务门禁**：三层并发防护，杜绝操作冲突
- **操作日志**：全流程操作记录，每一笔修改都有迹可循
- **质量门禁**：代码提交自动执行 9 项质量检查，保障系统稳定性
- **回归测试**：62 项自动化测试覆盖全部核心流程

## 七、应用场景

### 场景一：家装公司快速报价
设计师完成 CAD 图纸和效果图后，上传至系统，3 分钟内即可生成完整报价单。支持多套模板快速对比（标准型 vs 经济型），帮助客户快速决策。

### 场景二：施工队精准算量
工长获取 CAD 图纸后，无需等待设计师提供工程量清单，自行上传系统即可获得精准的空间面积数据和施工量，精准采购材料，减少浪费。

### 场景三：教学实训平台
作为智能建造、建筑信息化相关课程的实训案例，学生可完整体验「图纸→AI识别→融合报价」的全流程，理解数字化工具如何赋能传统行业。

### 场景四：装修业主核价
业主上传自家图纸和喜欢的装修效果图，系统自动生成透明的报价明细，对照装修公司的报价单逐项核对，做到心中有数。

## 八、快速体验

### 环境要求

- 任意 Windows / macOS / Linux 电脑
- Python 3.10+
- 8GB 内存（推荐 16GB）

### 三步开始

```bash
# 1. 安装 Ollama 并下载视觉模型
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5vl:latest

# 2. 下载并启动 BuildSight
git clone https://gitee.com/sjdliuxinfeng/buildsight.git
cd buildsight && bash start.sh

# 3. 打开浏览器访问
# → http://localhost:8100
```

> 💡 详细部署文档见项目 `docs/` 目录
