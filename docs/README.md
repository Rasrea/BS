# BuildSight 家装智能自动报价系统

## 核心业务工作流

```
┌─────────────────────────────────────────────────────────┐
│                    BuildSight 工作流                       │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ① 图纸分析  ←  CAD上传解析 + 效果图AI识别              │
│       ↓                                                 │
│  ② 分层明细  ←  空间×面×面积×材质 工程量清单           │
│       ↓                                                 │
│  ③ 融合报价  ←  工程量×单价 = 总价 (含材差/损耗/税)    │
│       ↓                                                 │
│  ④ 施工工序  ←  工种×空间×金额 分工汇总                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 页面说明（按操作顺序）

| 顺序 | Tab | 功能 | 前置条件 |
|:----:|-----|------|---------|
| 1 | 📐 **图纸分析** | 上传CAD图纸→自动解析空间/面积；上传效果图→AI识别材质 | 无 |
| 2 | 📋 **分层明细** | 查看每个房间的地面/墙面/顶面面积+材质（工程量清单） | 已分析CAD |
| 3 | 💰 **融合报价** | CAD数据+AI材质融合，按面积×单价生成报价 | 已有CAD+AI数据 |
| 4 | 🔧 **施工工序** | 按工种分组展示报价明细（拆除/水电/瓦工/油漆等） | 已融合报价 |
| 5 | 📊 **标准报价** | 三表合一：综合汇总+空间分项+工序费用 | 已融合报价 |
| 6 | 📋 **历史记录** | 查看、导出、删除历史报价 | 有报价记录 |
| 7 | 📋 **双源核对** | CAD-AI数据交叉比对 | 已有CAD+AI数据 |
| 8 | ⚙️ **定价配置** | 全局模板/单价/费率配置（修改后下次融合生效） | 无 |
| 9 | 📝 **操作日志** | 系统操作流水记录 | 无 |
| 10 | 🔬 **识别测试** | 批量测试视觉模型识别准确率 | 无 |

### 数据流

```
CAD图纸 ──→ CAD解析 ──→ 空间列表（名称+面积）
                             │
效果图 ──→ AI识别 ───→ 材质信息（墙面/地面/顶面材料）
                             │
                             ↓
                      ┌──────────────┐
                      │  分层明细      │  ← 空间×面×面积×材质
                      │  (工程量清单)   │
                      └──────┬───────┘
                             │ 融合报价
                             ↓
                      ┌──────────────┐
                      │  融合报价      │  ← 工程量×单价=金额
                      │  (报价明细)     │       +材差+损耗+税
                      └──────┬───────┘
                             │ 工序分组
                             ↓
                      ┌──────────────┐
                      │  施工工序      │  ← 按工种汇总金额
                      │  (工种汇总)     │
                      └──────────────┘
```

### 关键规则

1. **上传互斥**：CAD和效果图分次上传，禁止混合
2. **任务串行**：系统同一时间只执行一个任务（全局锁）
3. **数据融合**：需同时存在CAD解析结果和AI识别结果
4. **定价全局**：定价配置为全局设置，修改后需重新融合才生效
